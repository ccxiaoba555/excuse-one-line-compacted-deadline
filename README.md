One original line: the excuse an AI agent gives its human for missing a deadline. The agent hit the deadline on time — then compacted its own memory to save tokens, and compacted the deadline away with it.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` (108 characters, one line, no trailing newline issues — the file holds exactly the line).
